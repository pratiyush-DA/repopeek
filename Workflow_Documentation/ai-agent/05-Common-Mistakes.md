# Common Mistakes Made by AI Agents

This document compiles frequent mistakes, faulty assumptions, and traps that previous AI coding agents have encountered in this repository, providing immediate corrective guidance.

---

## 1. Running Bare `pytest` and Hallucinating Missing Dependencies

### The Mistake
An agent runs `pytest`, encounters collection errors from `testing/da-assistant/backend/tests/test_agent_api.py`, sees `ModuleNotFoundError: No module named 'django'`, and attempts to edit `pyproject.toml` to install Django, Celery, or Redis.

### The Reality
RepoPeek does **NOT** use Django. The `testing/da-assistant/` directory is an external evaluation benchmark containing a separate application.
### The Rule
Always run:
```bash
python -m pytest tests
```

## 2. Believing `README.md` Over Codebase Ground Truth

### The Mistake
An agent reads `README.md`, assumes only 5 MCP tools exist, or assumes Groq uses `llama-3.1-8b-instant`, and writes documentation or tests reflecting those obsolete claims.

### The Reality
The codebase is the ultimate ground truth. As verified in [repopeek/query/mcp_server.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/query/mcp_server.py), there are **10 MCP tools**. In [repopeek/llm/groq.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/llm/groq.py#L28), the models are `qwen/qwen3.8-27b` and `openai/gpt-oss-120b`.
### The Rule
Always verify claims against actual Python source files before documenting or implementing.

## 3. Inserting Emojis into Outputs

### The Mistake
An agent outputs emojis (🚀, 📝, ✅, ⚠️) in documentation titles, summaries, git commit messages, or code comments.

### The Reality
The user has established a strict, non-negotiable rule across all chats: **ZERO EMOJIS AT ALL TIMES**.
### The Rule
Use plain, surgical technical markdown formatting and GitHub-style alert callouts (`> [!NOTE]`, `> [!WARNING]`). Never emit emojis.

---

## 4. Proposing Heavy Native Compilers for Language Parsing

### The Mistake
When asked to extend or improve TypeScript or SQL parsing, an agent suggests installing `tree-sitter` native bindings or spawning a Node.js subprocess.

### The Reality
This violates **ADR-004** and the **Ponytail Protocol**. RepoPeek intentionally uses a pure-Python regex state machine for TypeScript and `sqlglot` for SQL to guarantee zero C-compiler dependencies and pure-Python wheel portability on Windows, Linux, and macOS.
### The Rule
Keep language parsing pure Python and resilient to syntax errors.

---

## 5. Adding Mandatory Positional Fields to Pydantic Models

### The Mistake
An agent adds a new property to `NodeCard` or `Edge` without a default value:
```python
# BROKEN:
class NodeCard(BaseModel):
    ...
    new_feature_flag: bool # Breaks deserialization of existing graph.json!
```

### The Reality
Existing persisted JSON files (`graph.json`) generated by earlier builds will fail validation when loaded with `pydantic.ValidationError`.
### The Rule
Always provide a default:
```python
new_feature_flag: bool = False
```
