# Behavioral Invariants

This document details the behavioral guarantees that RepoPeek maintains across indexing runs, query executions, and graph traversals.

---

## 1. Determinism and Reproducibility Invariant

- **Invariant:** Indexing the identical source code tree multiple times must produce byte-for-byte identical persistent JSON artifacts (`graph.json`, `manifest.json`, `lenses/*.json`, `shards/*.json`) with identical SHA-256 hashes.
- **Classification:** **Verified Invariant**.
- **Enforcement Mechanisms:**
  - Nodes are explicitly sorted by `node.id` ascending prior to serialization in [repopeek/storage/json_store.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/storage/json_store.py#L27).
  - Edges are explicitly sorted by `(edge.src, edge.dst, edge.type.value, edge.confidence.value)` in [repopeek/storage/json_store.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/storage/json_store.py#L31-L34).
  - JSON serialization is enforced with `indent=2, sort_keys=True, ensure_ascii=False`.
  - Non-deterministic object memory addresses (e.g. `hex(id(obj))`) are strictly excluded from node identifiers and hashes.

---

## 2. Graph Traversal Cycle Termination Invariant

- **Invariant:** Graph traversal routines (blast radius calculation, dependency resolution, data-flow def-use tracing) must terminate deterministically and never enter infinite loops, even when source code contains circular dependencies, mutually recursive functions, or cyclical imports.
- **Classification:** **Verified Invariant**.
- **Enforcement Mechanisms:**
  - [repopeek/analysis/blast_radius.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/analysis/blast_radius.py) maintains an in-memory `visited: Set[str]` tracking processed node IDs.
  - Hard traversal hop limit: Hops cannot exceed `max_depth` (default $H = 3$).
  - Downstream probability attenuation: Probabilities decay with path length ($0.85^d$). Traversal terminates early if accumulated probability drops below `min_risk` ($0.05$).

---

## 3. Fact Integrity and Hallucination Protection Invariant

- **Invariant:** Semantic narratives generated by LLMs must never contradict statically verified AST facts. If an LLM claims a function performs network I/O or accesses a database when AST analysis proves it does not, the hallucinated claim must be pruned.
- **Classification:** **Verified Invariant**.
- **Enforcement Mechanisms:**
  - [repopeek/enrichment/verifier.py](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/enrichment/verifier.py) performs post-generation verification:
    ```python
    if ast_facts.purity and story.has_side_effects:
        story.has_side_effects = False # Corrected by verifier
    ```
  - Unverified claims are filtered out before persistence to prevent poisoning downstream context packages.

---

## 4. Atomic Directory Persistence Invariant

- **Invariant:** The target storage directory (`.repopeek/`) must never be left in a corrupted, half-written state if indexing crashes or is killed by a signal.
- **Classification:** **Verified Invariant**.
- **Enforcement Mechanisms:**
  - [save_canonical_graph()](file:///c:/Users/pkumar2/OneDrive%20-%20Data%20Axle/Documents/AI_INIT/Repopeek/repopeek/storage/json_store.py#L84) writes all files to `.tmp_build_<uuid>`.
  - Only when all files and checksums are verified does an atomic directory swap take place.
  - Any caught exception triggers `shutil.rmtree(staging_dir, ignore_errors=True)` and preserves the pre-existing `.repopeek/` directory intact.

---

## 5. Model Schema Validation Invariant

- **Invariant:** Every node and edge inserted into `CanonicalGraph` must conform to the strict Pydantic model contract.
- **Classification:** **Verified Invariant**.
- **Enforcement Mechanisms:**
  - `NodeCard` requires non-empty `id`, valid `kind` string, and computed `content_hash`.
  - `Edge` enforces that `src` and `dst` are strings, `type` is a valid member of `EdgeType` enum, and `confidence` is a member of `Confidence` enum.
  - Invalid types or missing required fields raise `pydantic.ValidationError` immediately at the ingestion boundary.
