Title: RepoPeek: Give your AI coding assistant an interactive dependency map (82.5% benchmark context reduction, 100% local)

When you ask Cursor, Claude Code, or Windsurf to refactor code in a large repository, the default strategy is brute-force: ripgrep and full-file dumps. That burns context window budget and leaves the model unaware of downstream callers.

I built RepoPeek as an open-source, local-first code property graph engine for AI coding assistants:
- Maps 36+ languages into an embedded relational graph (NetworkX + SQLite, no Neo4j or cloud service needed).
- Context Compiler: Pinpoints precise 40-line AST spans instead of entire files.
- Change Impact Radar: Identifies affected callers and breaking risks before you commit an edit.
- Sub-50ms incremental watch daemon that syncs the graph on save.

Tested against 264 unit tests. Measured an 82.5% context reduction on a 3-defect benchmark (22,633 down to 3,966 tokens), with 17.7% net savings across the full benchmark suite.
